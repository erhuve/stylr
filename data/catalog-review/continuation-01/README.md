## Method and checks

The input is the earlier 782-entry queue at `../remaining-review-queue.json`. Selection cycles through alphabetically sorted sources, taking each source's next candidate in its existing queue order until 120 are selected, then groups the selected records by source and ID for inspection. This favors source breadth; it is not a random or coverage-optimized sample. Source pages can repeat models and garments.

The apparent-build and local-axis anchors follow `../README.md`: build 1/1.5/2/2.5/3, shoulder/hip -1/0/1, waist 0/1/2. Each axis remains independently nullable. Clothing descriptions are separate visual notes, not inferred body traits or machine-normalized style tags.

An enlarged same-reviewer reread inspected all ten initially complete records. Record 35 lost its shoulder/hip label because loose shorts inflate hip width. `reread.json` preserves this correction; the reread sheet displays the pre-correction labels. This is not independent agreement or a calibrated accuracy study.

`observations.tsv` is authored evidence. `manifest.json` fixes ordinal-to-ID, source and SHA-256 bindings. `labels.json`, `summary.json` and `remaining-review-queue.json` are generated by the audit. The audit verifies current catalog metadata, all 120 image digests, unique and disjoint IDs, ordinal coverage, allowed axis values, correction replay and exact remaining-queue partition.

Recompute with `python /home/workspace/Documents/stylr-catalog-pilot/review_remaining.py audit`. `prepare` recreates the primary contact sheets and refuses to replace a changed manifest. It does not generate observations. No network, classifier, app build or dependency installation is needed.
